# Defender of Dreams / «Защитник снов»

Atmospheric **2D** action-adventure / roguelite / narrative for the browser (PC).  
You play as the soul of **Nero**, stranded in the world of forgotten dreams — the *Other Side* (Изнанка).

**Working English title:** Dream Keeper  
**Engine:** Unity 6 LTS · **Target:** WebGL · **Art:** pixel-art, top-down view

## Core mechanic

Limited visibility and a **fog of forgetting** that returns to explored areas unless they are locked with a limited resource — **Memory Anchors**.

## Getting started

1. Install **Unity 6 LTS** with WebGL Build Support.
2. Open this folder as a project (Unity Hub → *Add project from disk*).
3. Open `Assets/Scenes/SampleScene.unity` and press **Play**.
